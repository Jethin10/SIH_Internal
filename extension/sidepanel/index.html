        Security and data use
        
Page inspection and private-value aliasing happen locally. Only minimized text context reaches your chosen model; raw screenshots are not sent to it. Keys and your private profile are stored for the browser session. Each proposed action is checked against the current page and task, and high-risk actions require Allow once. Detection can miss sensitive text, and a model can make mistakes. Speech recognition and speech synthesis may use browser or operating-system services outside this gateway. Review transcripts before running and inspect each booking confirmation.
